# Fiche projet — App Partage

- **Format :** Modèle hybride
- **Mode de travail :** Individuel
- **Pour qui :** Personnes qui cherchent ou veulent rendre service
- **Problème, besoin ou désir :** Proposer ou trouver des services comme aide à monter meuble, déplacer, babysitting,
- **Première version très simple :** Page d'accueil avec menu, voir services proposés, pouvoir publier son service
- **Hors formation :** Tout ce qui rend le visuel attrayant, le paiement
